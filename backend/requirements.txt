# the floor it allows carries known advisories. 0.50.0 was held here while

#                          refused over plain HTTP, so a path that reparses
#                          differently is a way past that control.
#   PYSEC-2026-249         request.form() silently ignoring max_fields and
#                          max_part_size for urlencoded bodies.
#   PYSEC-2026-2280        HTTPEndpoint dispatching on arbitrary attribute
#                          names (unused here).
#   PYSEC-2026-2281        StaticFiles UNC path traversal (Windows only; this
#                          ships as a Linux container).
